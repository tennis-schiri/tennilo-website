Product data sheet · Features

Club life

Fixtures, results, events and news with an internal article reader. Sources are checked for each club.

Automatic information mode

Rotating slides, countdown, pause, manual navigation and return after inactivity. German and English.

Sponsors & dining

Individual logos, offers, opening hours and notices. Content updates by arrangement.

Weather

Current weather, forecast and radar from external weather sources, subject to availability.

Courts & booking

Interactive booking terminal via a compatible existing system. Live occupancy with names and time windows prepared; API approval and privacy review required.

Team welcome

Automatically from 30 minutes before until 30 minutes after scheduled home match start. Court numbers only when confirmed.

Requirements & setup

Hardware

  • Recommended: 24–43 inches, Full HD (1920 × 1080), landscape.
  • Mini PC or existing computer, Windows 11 recommended; current browser.
  • Touchscreen for interaction; ordinary monitor for display-only use.

Operation

  • Stable internet, power and suitable kiosk/autostart setup.
  • Club logo, colours, contact and approved data sources.
  • Protected club administration for content and display profiles after activation; separate TENNILO operator access.

Integrations & privacy

  • nuLiga/WordPress subject to compatibility checks; no official partnership implied.
  • Booking-system licence and terminal/API approval from provider and club.
  • Personal booking data only with lawful display and access safeguards.

Hosting & technical infrastructure

Managed hosting (planned)

Standard hosting, HTTPS, technical updates and basic support are intended to be included in the licence. A separate club-specific display URL is provided; no own hosting or domain is required. Scope, backups and support response times must be agreed before sale.

Own webspace (by arrangement)

A club domain or subdomain with HTTPS and PHP 8.2 or newer (supported security version; PHP 8.3+ recommended), cURL, DOM/XML, SimpleXML, JSON, writable private temporary/cache directories with file locking and outbound HTTPS to approved data providers. Secure FTPS/SFTP or an agreed deployment method. A separate database is not required by the current display version.

Security & responsibilities

Separate club configuration, protected credentials and terminal access; GDPR-compliant hosting and data processing agreement where required. Booking/API permissions, external provider availability and on-site internet are prerequisites. Own hosting requires a compatibility check and an agreed maintenance model; not a standard self-install package yet.
